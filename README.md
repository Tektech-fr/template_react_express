<h1 align="center">Bienvenue sur template_react_express 👋</h1>
    
## 📖 Description

Le template React Express est un modèle de projet qui combine les puissantes fonctionnalités de React pour le développement frontend avec la robustesse d'Express pour le backend. Il est conçu pour faciliter le démarrage rapide de projets web modernes en fournissant une structure de base solide et des configurations prêtes à l'emploi.

## 🚀 Installation

1. Clone le dépôt :

    ```bash
    git clone git@github.com:Tektech-fr/template_react_express.git
    ```

2. Accède au répertoire du projet :

    ```bash
    cd template_react_express
    ```

3. Installe les dépendances pour le client :

    ```bash
    cd client
    npm install
    ```

4. Installe les dépendances pour le serveur :

    ```bash
    cd server
    npm install
    ```
